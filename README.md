# Image2pdf

Image2pdf is a simple utility that ingests image files and combines them into a single PDF document.

## What it does

- Accepts image input in any format supported by your environment.
- Combines one or more images into one large PDF.
- Lets the user choose the output PDF name.
- Produces a portable PDF that can be saved, shared, or archived.

## Typical workflow

1. Provide the images you want to include.
2. Choose the order of pages/images.
3. Enter the name for the output PDF.
4. Generate and save your PDF.

## Use cases

- Scan-like document compilation
- Combining photos into one file
- Sharing multiple images as a single attachment
